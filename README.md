# The Iona School Demo Website

A polished static demo website concept for **The Iona School**, a primary school in Nottingham, UK.

This is presentation/demo content only. Placeholder copy, sample news, sample testimonials, and generated photography should be replaced with school-approved information before official use.

## Preview

```powershell
npm start
```

Then open:

```text
http://localhost:3000
```

## Included

- Responsive one-page school website with navigation sections
- Hero, welcome, school highlights, values, curriculum, admissions, parents, news, gallery, testimonials, and contact
- Local demo photography under `assets/iona-school/`
- Mobile hamburger menu
- Demo contact form feedback
- Google Maps search link for the provided address
